# Algoritmos em ação

Projeto com exemplos interativos de algoritmos em JavaScript e testes automatizados com Jest.

## Requisitos

- Node.js e npm

## Instalar dependências

Na raiz do projeto, execute:

```bash
npm install
```

## Executar os testes

Rode todos os testes com:

```bash
npm test
```

Para executar o Jest em modo serial:

```bash
npm test -- --runInBand
```

Os testes cobrem contagem de inteiros, Fibonacci, máximo divisor comum (MDC), identificação de números primos, ordenação por quicksort e somatória.
